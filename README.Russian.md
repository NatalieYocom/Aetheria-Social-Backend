# BasisVR Social Service

Комплексный социальный серверный бэкенд для BasisVR, созданный на Go. Этот сервис обеспечивает общение в реальном времени, отслеживание присутствия пользователей, потоковую передачу активности и возможности федерации для экосистемы BasisVR.

## Обзор

BasisVR Social Service — это полнофункциональное приложение, которое обеспечивает функции социальных сетей для BasisVR. Оно предоставляет надежный серверный API, потоковую передачу событий в реальном времени и опциональную поддержку федерации ActivityPub.

### Ключевые возможности

- **Управление пользователями**: Регистрация, аутентификация и управление профилями
- **Общение в реальном времени**: Потоковая передача событий в реальном времени на основе WebSocket с использованием Redis
- **Отслеживание присутствия**: Отслеживание и трансляция присутствия пользователей на платформе
- **Ленты активности**: Потоковая передача социальной активности и генерация лент
- **Управление активами**: Интеграция с каталогами активов для управления контентом
- **Федерация**: Опциональная поддержка ActivityPub для федерации с другими платформами
- **Наблюдаемость**: Встроенные возможности метрик, трассировки и логирования
- **Масштабируемость**: Разработан для горизонтального масштабирования с использованием Redis и PostgreSQL

## Технологический стек

### Backend
- **Язык**: Go
- **Веб-фреймворк**: Стандартный Go HTTP сервер
- **База данных**: PostgreSQL 16
- **Кэширование & Pub/Sub**: Redis 7
- **Файловое хранилище**: MinIO (S3-совместимый)

### Услуги
- **API Server**: Main REST/WebSocket API
- **Служба доставки**: доставка сообщений ActivityPub и федерация
- **Сервис хранения данных**: Политики очистки и хранения данных

### Наблюдаемость
- **Метрики**: Prometheus
- **Визуализация**: Grafana
- **Трассировка**: OpenTelemetry Collector

## Структура проекта

Репозиторий организован следующим образом:
- **backend/**: Исходный код бэкенда на Go
- **frontend/**: Фронтенд-приложение
- **deploy/**: Конфигурации развертывания
- **infra/**: Конфигурации инфраструктуры (Prometheus, Grafana, OTEL)
- **DOCS/**: Подробная документация
- **docker-compose.yml**: Полная настройка среды разработки

## Быстрый старт

1. Клонируйте репозиторий
2. Выполните `docker-compose up`, чтобы запустить все сервисы
3. Получите доступ к API по адресу `http://localhost:8080`

Все зависимые сервисы (PostgreSQL, Redis, MinIO) запускаются автоматически с проверками работоспособности.

## Ключевые сервисы

- **Backend API** (Порт 8080): Основной REST/WebSocket API с JWT-аутентификацией
- **PostgreSQL** (Порт 5432): Основное хранилище данных
- **Redis** (Порт 6379): Публикация/подписка в реальном времени и кэширование
- **MinIO** (Порт 9000/9001): S3-совместимое объектное хранилище
- **Prometheus** (Порт 9090): Сбор метрик
- **Grafana** (Порт 3000): Визуализация метрик
